Este programa permite modificar las taxas de Pontevedra y envia por correo registro de cuando se inicia sesión y se modifican las Taxas, también almacena logs de forma local. 

Se ha subido el código fuente pero se ha colocado en comentarios información como IPs, usuarios, base de datos y tokens de correo, de forma genérica para su correcto funcionamiento se debe cambiar por los valores reales.
